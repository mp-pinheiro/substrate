# Security policy

## Supported versions

Security fixes are made on the default branch. Until tagged releases exist, only the current `main` branch is supported.

## Report a vulnerability

Do not open a public issue or pull request. Use GitHub's [private vulnerability reporting form](https://github.com/mp-pinheiro/substrate/security/advisories/new).

Include:

- the affected commit or version;
- the affected command, hook, workflow, or profile;
- the impact and required attacker access;
- minimal reproduction steps; and
- any known mitigation.

Remove credentials, personal data, and unrelated repository content from the report. If a real credential was exposed, revoke or rotate it before reporting it.

The maintainer will coordinate validation, remediation, and disclosure through the advisory. Please allow time for a fix before publishing details.
